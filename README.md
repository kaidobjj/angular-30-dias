# Angular en 30 días — Día 1

Proyecto listo para abrir en **Visual Studio Code**.

## Requisitos
- Node.js 20.19+ o 22.12+ (recomendado Node.js 22 LTS compatible)
- npm

## Inicio
1. Descomprime el ZIP.
2. Abre la carpeta `angular-30-dias` en Visual Studio Code.
3. Abre la terminal integrada (Ctrl + `).
4. Ejecuta `npm install`.
5. Ejecuta `npm start`.

La aplicación se abrirá normalmente en http://localhost:4200.

## Ejercicios del Día 1
1. Cambia el título.
2. Crea un botón para sumar 5.
3. Evita valores negativos.
4. Muestra un mensaje con `@if` cuando el contador sea 10 o mayor.

Archivos para modificar:
- `src/app/app.component.ts` (lógica)
- `src/app/app.component.html` (vista)
- `src/styles.css` (estilos)

Cuando termines, comparte el código o los errores en el chat para revisarlos y pasar al Día 2.
